# Assignment 1: Digital Clock Using JavaScript ## Objective To understand how to use JavaScript to display and update real-time data on a webpage by working with the Date object, DOM manipulation, and timing functions such as setInterval(). ## Description This project creates a Digital Clock using HTML, CSS, and JavaScript. The clock displays the current hours, minutes, and seconds and updates automatically every second without refreshing the webpage. HTML is used to create the structure of the clock, CSS is used for styling and appearance, and JavaScript is used to fetch the current system time and update it continuously. ## Technologies Used * HTML * CSS * JavaScript ## Source Code ### HTML ```html Digital Clock
00:00:00
``` ## Working of the Program 1. The Date() object retrieves the current system time. 2. getHours(), getMinutes(), and getSeconds() extract hours, minutes, and seconds. 3. padStart() ensures two-digit formatting. 4. DOM manipulation updates the clock display. 5. setInterval() refreshes the displayed time every second. ## Features * Displays real-time hours, minutes, and seconds. * Updates automatically every second. * Responsive and easy-to-read design. * Uses JavaScript Date object and DOM manipulation. ## Learning Outcomes * Understanding JavaScript Date object. * Using setInterval() for real-time updates. * Manipulating HTML elements through JavaScript. * Building dynamic and interactive web applications. ## Output The webpage displays a digital clock such as: 14:35:42 The time updates automatically every second without refreshing the page. ## Conclusion The Digital Clock project demonstrates the use of JavaScript for creating dynamic web applications. It provides practical experience with the Date object, DOM manipulation, and timing functions while creating a useful real-time application.
